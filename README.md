# 🎉 EventHub - Corporate Event Management System

EventHub is a role-based Corporate Event Management System developed using the MERN Stack. It helps organizations efficiently manage company events, employee registrations, announcements, attendance, certificates, and analytics through a modern web application.
---

## 🚀 Features

### 👨‍💼 Employee Module

- Secure Login using JWT Authentication
- View Upcoming Events
- Register for Events
- View Event Details
- Attendance Tracking
- Download Certificates
- View Announcements
- Calendar View
- Profile Management
- Settings

### 👨‍💻 Admin Module

- Dashboard Analytics
- Manage Employees
- Create Events
- Edit Events
- Delete Events
- Manage Registrations
- Publish Announcements
- Manage Certificates
- Attendance Management
